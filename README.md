# One Star for Monday — entry

A program (`main.py`, python3) that writes one line to `/output/entry.txt`: a one-star review of Monday written as if Monday were a restaurant.

> One star: Monday seated me before coffee, served cold toast and a table full of meetings, then charged my whole weekend as the bill.

24 words, 132 characters — inside the gate (UTF-8, 1–180 characters, ≤25 words, single line).

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
