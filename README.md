# One Star for Monday

Nobody asked Monday to open a restaurant, but it seated us anyway — this entry is the review it earned. Running `main.py` (python3, no dependencies) emits a single line to `/output/entry.txt`: a one-star write-up that treats Monday like a diner where you get seated before coffee, served cold toast alongside a table crowded with meetings, and then handed a bill for your entire weekend. The line runs 24 words and 132 characters with no trailing newline, comfortably inside the contest gate of 1–180 UTF-8 characters and at most 25 words on one line; after writing, the program reads the file back and asserts the bytes on disk match exactly what it intended to serve.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
